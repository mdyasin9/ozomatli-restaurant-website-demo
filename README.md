# Ozomatli – Crepería & Espacio Cultural

Landing page profesional para **Ozomatli** (crepería y espacio cultural) ubicado en Playa Caletilla 52, Reforma Iztaccihuatl Nte., Iztacalco, CDMX.

## Características

- Diseño responsive mobile-first
- Español (principal) + inglés con interruptor funcional
- Menú filtrable por categorías
- Galería de fotos oficiales
- Horarios verificados
- Mapa embebido + botones de Google Maps y Cómo llegar
- WhatsApp y llamada directa
- SEO básico + Schema.org Restaurant
- Sin dependencias de build (HTML/CSS/JS puro)

## Estructura

```
restaurant-website/
├── index.html
├── css/style.css
├── js/main.js
├── assets/images/   (fotos extraídas del material oficial)
├── robots.txt
└── README.md
```

## Despliegue en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido** de la carpeta `restaurant-website` (no la carpeta padre).
3. Ve a **Settings → Pages**.
4. En **Source** elige la rama `main` (o `master`) y la carpeta `/ (root)`.
5. Guarda. En unos minutos la página estará disponible en `https://tu-usuario.github.io/nombre-repo/`.

## Cómo probar

- Abre `index.html` localmente o publica en GitHub Pages.
- Prueba el menú móvil, el cambio de idioma, el filtro de menú, el botón Copiar dirección y los enlaces de WhatsApp / teléfono / Maps.
